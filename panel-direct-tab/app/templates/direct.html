Один токен открывает столько кабинетов, представителем скольких является его владелец. Перечислить их через API нельзя: AgencyClients.get отвечает «оператор не является представителем агентства». Логины видны только в интерфейсе — Директ Про → «Доступные аккаунты». Скопируйте оттуда список целиком и вставьте сюда: подписи вида «Бренд A · Редактор» отбрасываются сами. Домен каждого кабинета панель определит по ссылкам его объявлений — из логина он не выводится, Яндекс выдаёт их вида brand-a-100001-k7x2.
