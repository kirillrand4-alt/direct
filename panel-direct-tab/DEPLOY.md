# Вкладка «Директ» в панели SEO Статистики — как выложить

Пакет добавляет в панель (`parsercompressor.online/stat/`) вкладку **Директ**
с рекламной статистикой из Яндекс Директа (API v5, сервис Reports).

Собрано под снимок панели `seostat_app-fix-miralinks-retry.zip` (от 05.08).
Изменение **добавочное**: 4 новых файла + 2 точечные правки существующих —
поэтому оно ложится поверх любой более свежей версии панели и не затирает
правки соседних сессий.

---

## Что меняется

**Новые файлы (4):**

| Файл | Назначение |
|---|---|
| `app/providers/yandex_direct.py` | клиент Reports API: Bearer-токен, очередь отчёта `201/202 + retryIn`, парсинг TSV |
| `app/services/direct.py` | агрегация: итоги, разбивка по дням и по кампаниям, CTR/CPC/CPA |
| `app/api/routes_direct.py` | страница `/direct`, экспорт CSV, сохранение токена и Client-Login |
| `app/templates/direct.html` | сама вкладка: плитки KPI, график, таблица кампаний, блок настроек |

**Правки существующих файлов (2, делает скрипт):**

| Файл | Правка |
|---|---|
| `app/main.py` | `routes_direct` добавлен в импорт и в цикл `include_router` |
| `app/templates/partials/nav.html` | пункт меню «Директ» после «Ошибки 404» |

`admin.html` **не трогается** — настройки токена вынесены на саму вкладку.

---

## Выкладка

1. Распаковать пакет на сервере во временную папку.
2. Из неё выполнить (путь — корень панели, тот, где лежит каталог `app/`):

   ```
   python apply_direct_tab.py --app-root C:\seostat
   ```

   Скрипт идемпотентный: повторный запуск ничего не задваивает. Перед правкой
   делает копии `main.py.bak-direct` и `nav.html.bak-direct`.

3. Перезапустить службу панели обычным способом.

Проверка: в меню появился пункт **Директ**, страница `/stat/direct` открывается.

### Откат

```
copy app\main.py.bak-direct app\main.py
copy app\templates\partials\nav.html.bak-direct app\templates\partials\nav.html
```
и перезапуск. Четыре новых файла можно оставить — без регистрации роутера они
не подключаются и ни на что не влияют.

## Первый запуск: подключить токен

Токен нигде в коде не зашит. После выкладки:

1. Открыть вкладку **Директ** → развернуть блок **«Настройки Директа»**.
2. Вставить общий OAuth-токен Директа → «Сохранить токен».
3. Если у домена свой рекламный аккаунт — выбрать домен и заполнить
   **Client-Login** (для агентских аккаунтов) и/или **отдельный токен для домена**.

Токены хранятся в существующем зашифрованном хранилище панели
(`app/credentials.py`, таблица `AppSetting`, шифрование ключом от `SECRET_KEY`) —
там же, где токены Вебмастера и Метрики. В `.env` ничего править не нужно,
перезапуск после ввода токена не требуется.

Ключи в хранилище:

| Ключ | Что |
|---|---|
| `yandex_direct_token` | общий OAuth-токен |
| `direct_token:<домен>` | токен для конкретного домена (перекрывает общий) |
| `direct_login:<домен>` | `Client-Login` домена (для агентских аккаунтов) |
| `direct_goals:<домен>` | ID целей Метрики через запятую — включает колонки конверсий |
| `direct_sandbox` | `1` = ходить в песочницу вместо боевого API |

Как получить сам токен — см. `README.md` в корне этого репозитория (пошагово,
с нуля: регистрация приложения, заявка на доступ, обмен кода на токен).

## Что показывает вкладка

- **Выбор домена** и период (по умолчанию — последние 28 дней, как на остальных вкладках).
- **Плитки:** Показы, Клики, CTR, Расход ₽, Цена клика; при заданных целях — Конверсии и Цена конверсии.
- **График по дням:** клики, показы, расход (три оси, Chart.js — как на дашборде).
- **Таблица по кампаниям:** показы, клики, CTR, расход, CPC (+ конверсии и CPA, если заданы цели), сортируемая.
- **Экспорт CSV** по кампаниям за период (с BOM — Excel открывает кириллицу корректно).

## Что заложено внутри (и почему)

- **`returnMoneyInMicros: false`** — иначе Директ отдаёт суммы умноженными на 1 000 000.
- **Уникальный `ReportName`** (с меткой времени) — иначе повтор с тем же именем и
  другими параметрами отдаёт ошибку.
- **Цикл ожидания `201/202`** с уважением заголовка `retryIn`; потолок ожидания
  ограничен, чтобы не подвешивать воркер. Если отчёт не успел — на вкладке
  человеческое сообщение, а не 500.
- **Ошибки Директа** (истёкший токен, отклонённый запрос, лимиты) показываются
  текстом на вкладке.
- **Конверсии — только при заданных целях.** Поле `Conversions` запрашивается
  лишь когда для домена указаны цели Метрики: у аккаунтов без целей запрос с этим
  полем отвалился бы ошибкой.
- **Кэш страниц.** Панель кэширует отрисованные страницы (`page_cache_ttl`, по
  умолчанию час) — это же бережёт баллы Директа. Формы сохранения токена
  редиректят с `nocache=1`, поэтому новое состояние видно сразу; принудительный
  сброс — кнопка 🧹 в шапке.

## Тесты

`tests/test_direct.py` — 8 тестов на respx (он уже в зависимостях панели):


## Известные ограничения

- Статистика тянется **живьём** при открытии вкладки и не пишется в БД панели —
  истории и сравнения периодов по Директу пока нет. Если понадобится (графики за
  год, сопоставление с органикой на дашборде) — это следующий шаг: таблица
  + сбор в `app/scheduler/jobs.py` рядом с остальными источниками.
- Данные Директа догоняются задним числом несколько дней (скрутка, НДС), поэтому
  цифры за последние дни могут ещё измениться.
- Разрез только по кампаниям. По фразам/поисковым запросам — тот же провайдер,
  добавляется одним методом с другим `ReportType`.
